Disease Severity Levels

Severity helps decide how urgently the field should be treated.

🟢

Low Severity

Limited visible damage. Monitor the plants regularly and take preventive action.

🟡

Medium Severity

Noticeable disease symptoms. Treatment should be planned soon to reduce possible crop loss.

🔴

High Severity

Serious crop damage. Immediate assessment and recommended disease-management action are required.

Treatment Advisory

Recommended actions based on disease severity and field condition.

🚨 Immediate Action

For high severity fields, inspect affected plants, reduce possible spread and seek appropriate agricultural guidance without unnecessary delay.

💊 Treatment

Follow crop-specific disease management recommendations, product labels and advice from qualified agricultural experts. Do not use an unknown chemical or dosage.

🔍 Continuous Monitoring

Inspect nearby plants regularly and update the field status if symptoms increase or spread.

Technical and Non-Technical Workflow

The system is designed so that farmers can use the simple interface while technical users can understand the underlying architecture.

👨‍🌾 For Farmers

  • Upload or capture a crop leaf image.
  • Select crop and field.
  • View disease and severity information.
  • Understand urgency in simple language.
  • Listen to the result using voice support.
  • Check which field should receive attention first.

🧑‍💻 For Technical Users

  • Frontend: HTML, CSS and JavaScript.
  • Image input through browser camera/file upload.
  • Disease classification can be connected to MobileNetV2, EfficientNet or another CNN model.
  • Severity can be calculated using model output, image segmentation or severity rules.
  • Yield-loss estimation can use crop-specific loss curves.
  • Priority can use severity, loss, cost and spread-risk scores.

🧠 ML / AI Requirements

  • Plant disease image dataset such as PlantVillage or another suitable dataset.
  • Image preprocessing and augmentation.
  • Trained crop disease classification model.
  • Severity estimation logic or trained severity model.
  • Crop-specific yield-loss assumptions or data.
  • Model API/backend for connecting the trained model to this interface.

⚙️ Backend Requirements

  • Python backend can be used for the ML model.
  • Flask or FastAPI can expose an API endpoint.
  • The frontend sends the image to the backend.
  • Backend preprocesses the image.
  • ML model predicts disease and severity.
  • Backend returns JSON results to the frontend.
